      Teach it with your own images

      Pick images (or a folder), type what each one shows, press Train. The engine learns which words go with which colours and layout, in a coarse 16×16 colour grid. It does not learn to draw new objects. Captions of 2–6 words work best, and a few dozen images already show an effect. You can train again later: new images are added to what it already knows.
